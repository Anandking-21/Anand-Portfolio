MongoDB-Automated-Backup

An automated, mission-critical Shell daemon engineered to solve unmanaged database loss. Provides scheduled hot database snapshots, Gzip archive compression, rotation retention policies to conserve disk space, and scheduled cron jobs to ensure dependable disaster recovery.

Shell Automation MongoDB Database Cron Scheduling Disaster Recovery
Inspect Repository Code
mongo_backup.sh POSIX Bash 
# Automated Backup & Rotation Engine
BACKUP_DIR="/var/backups/mongodb"
TIMESTAMP=$(date +"%Y%m%d_%H%M%S")
TARGET="$BACKUP_DIR/backup_$TIMESTAMP"

# Hot compression execution
mongodump --out "$TARGET" --gzip
echo "[SUCCESS] Snapshot complete: $TARGET.tar.gz"
# Retention policy: Prune records older than 14 days
find "$BACKUP_DIR" -type d -mtime +14 -exec rm -rf {} +
